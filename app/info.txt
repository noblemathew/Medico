I'm building "Insight IQ", a universal Excel report analysis tool in Python (CustomTkinter desktop app). Build a standalone module `table_finder.py` that can extract tables from ANY messy Excel report, with no predefined template.

Requirements:
1. Open .xlsx files with openpyxl (data_only=True) and process every sheet.
2. Handle merged cells by filling each merged range with its top-left value.
3. Detect multiple separate tables in a single sheet: group filled cells into blocks separated by empty rows/columns (configurable gap, default 1). Return the bounding box of each block.
4. For each block, detect the header row automatically: the first row (within the first ~5 rows) that is mostly text and is followed by rows containing numbers/dates. Support multi-row headers by combining them (e.g. "Sales - Units").
5. Treat any text rows above the header as the table title.
6. Make column names unique and fill blanks with col_1, col_2, etc.
7. Return each table as a pandas DataFrame along with: sheet name, cell range, title.
8. Profile every column and classify it as one of: date/week, numeric measure, category, ID, or text. Detect dates even when they're stored as text or as week labels like "W46 2026".
9. Add a function `load_folder(path)` that opens every Excel file in a folder, matches tables with the same/similar headers across files, and stacks them in date order, so history spread across multiple files becomes one continuous table.
10. Add a `confirm/override` mechanism: save a small JSON config per report (keyed by file name pattern + sheet) where the user can fix table ranges, header rows, or column types once, and the tool reuses it next time.
11. Add a `summarize_structure(tables)` function that returns ONLY metadata (sheet, table title, column names, column types, row count, date range) and no raw values. This is what will later be sent to an AI model, so it must never include actual data values.

Constraints:
- All processing must stay local. No network calls.
- Use only openpyxl, pandas, numpy and the standard library.
- Write clean, well-commented, complete code (no placeholders), with type hints.
- Include a `__main__` block that takes a file path, prints every detected table with its location, title, column types, and the first 5 rows.
- Also generate a test script that creates 3 messy dummy Excel files (multiple tables per sheet, merged title cells, blank gaps, a 52-week sales table split across two files for 2025 and 2026) and runs the extractor on them.
